# แบบฝึกหัด EP13 — แผนที่สถานีเครือข่ายโทรคมนาคม

ใช้ข้อมูลสถานีสมมติ 6 จุดจาก [README](../README.md)

พิกัดและค่าข้อมูลไม่ใช่ข้อมูลสถานีจริง และวงกลมบนแผนที่ไม่ใช่พื้นที่ครอบคลุมสัญญาณ

## 1. อ่านพิกัดของสถานี

- ระบุ Longitude และ Latitude ของ Site C
- เขียนลำดับอาร์กิวเมนต์ที่ส่งให้ `m(...)`
- ระบุว่าแต่ละค่าอยู่ทางตะวันออกหรือตะวันตก และทางเหนือหรือใต้

ผลที่ต้องส่ง: พิกัดหนึ่งคู่และคำอธิบายหน่วย

## 2. เปรียบเทียบวิธีวางจุด

สร้างแผนที่สองใบโดยใช้ขอบเขตเดียวกัน

- ใบแรกใช้ `x, y = m(longitude, latitude)` แล้วส่งให้ `ax.scatter()`
- ใบที่สองใช้ `m.scatter(longitude, latitude, latlon=True)`
- ให้ทั้งสองใบใช้จุดขนาดเดียวกันและสีเดียวกัน

ผลที่ต้องส่ง: ภาพสองใบและคำอธิบายว่าตำแหน่งต่างกันหรือไม่

คำถาม: ถ้าแปลงเป็น X/Y แล้ว ยังต้องใช้ `latlon=True` หรือไม่?

## 3. เปลี่ยนค่า Traffic หนึ่งสถานี

สร้างสำเนาก่อนแก้:

~~~python
traffic_changed = traffic_mbps.copy()
traffic_changed[2] = 760
~~~

- วาดข้อมูลเดิมและข้อมูลใหม่โดยใช้ช่วงสี 0–800 Mbps เหมือนกัน
- ตรวจว่าพิกัดสถานีไม่เปลี่ยน
- ตรวจว่าค่าเดิมของ Site C ใน `traffic_mbps` ยังเป็น 310

ผลที่ต้องส่ง: ภาพเปรียบเทียบและชื่อสถานีที่เปลี่ยนสี

คำถาม: เมื่อค่า Traffic เพิ่ม ขนาดจุดจำเป็นต้องเพิ่มด้วยหรือไม่ ถ้า `s` ใช้จำนวนผู้ใช้งาน?

## 4. เปลี่ยนขนาดสัญลักษณ์

- เปลี่ยนตัวคูณขนาดจาก `connected_users * 1.5` เป็น `connected_users * 2.0`
- เปลี่ยนตัวคูณของตัวอย่างขนาดใน Legend ให้ตรงกัน
- คงค่าจำนวนผู้ใช้งานและค่า Traffic เดิม

ผลที่ต้องส่ง: แผนที่พร้อม Legend และคำอธิบายว่าสิ่งใดเปลี่ยนหรือไม่เปลี่ยน

คำถาม: วงกลมใหญ่ขึ้นหมายถึงระยะส่งสัญญาณไกลขึ้นหรือไม่?

## 5. เปลี่ยนขอบเขตที่มองเห็น

ใช้ Longitude 98–104 และ Latitude 15.5–17.5

- สร้าง Basemap ใหม่ตามขอบเขตนี้
- เลือกเฉพาะสถานีในขอบเขตด้วย Boolean Mask
- กรองชื่อสถานีและค่า Traffic ด้วย Mask เดียวกัน
- คงช่วงสี 0–800 Mbps

ผลที่ต้องส่ง: แผนที่ใหม่และรายชื่อสถานีที่ยังอยู่ในภาพ

คำถาม: สถานีที่ไม่อยู่ในภาพถูกลบจาก Array ต้นฉบับหรือไม่?

## 6. อ่านแผนที่อย่างมีข้อจำกัด

พิจารณาคำถามต่อไปนี้:

- สถานีใดมี Traffic มากที่สุดในข้อมูลตัวอย่าง?
- สถานีใดมีผู้ใช้งานที่เชื่อมต่อมากที่สุด?
- วงกลมทับกันบอกได้หรือไม่ว่าสัญญาณรบกวนกัน?
- ข้อมูลนี้บอกได้หรือไม่ว่าสถานีใดมีความจุไม่เพียงพอ?

ผลที่ต้องส่ง: แยกคำถามที่ตอบได้จากข้อมูลนี้ กับคำถามที่ต้องมีข้อมูลเพิ่มเติม
