# EP8 Illustration Brief

สร้างภาพอธิบายโรงงานบรรจุภัณฑ์แบบ 16:9 ด้วยมุมมอง Isometric สามมิติ มีสายการผลิตสามเส้นแยกสีชัดเจน แต่ละ Line ต้องมีเครื่องจักร สายพาน กล่องสินค้า Motor/ชุดเกียร์ติดตั้งอยู่ใต้สายพาน ตู้ควบคุมไฟฟ้าพร้อม HMI กล้องตรวจสอบคุณภาพ และจุดคัดแยกสินค้าเสียของตัวเอง โดยอุปกรณ์ต้องมีขนาดทางกายภาพเท่ากันและย่อขนาดบนภาพตาม Perspective พร้อมวางโลโก้ KOPE SOLUTION เวอร์ชันสีอ่อนในตำแหน่งที่อ่านง่ายและไม่บังข้อมูล

ข้อความที่ใช้ในภาพมีเพียง `LINE A`, `LINE B`, `LINE C`, `OUTPUT RATE`, `MOTOR TEMPERATURE`, `VIBRATION` และ `DEFECT RATE` โดยใช้ลูกศรชี้จากชื่อตัวแปรไปยังอุปกรณ์หรือจุดวัดที่เกี่ยวข้อง ภาพใช้พื้นหลังสีน้ำเงินเข้มและสี Cyan สำหรับลูกศร เพื่อให้เข้ากับเนื้อหาเชิงเทคนิคและอ่านได้ชัดบนวิดีโอ
