# แบบฝึกหัด EP14 — งานทำความสะอาดห้องพักในโรงแรม

ใช้ DataFrame `jobs` จาก [README](../README.md)

ข้อมูลเป็นข้อมูลสมมติ ไม่ใช่เกณฑ์เวลาทำงานหรือเกณฑ์ประเมินพนักงาน

## 1. อ่านแถวและคอลัมน์

- อธิบายความหมายของหนึ่งแถวใน `jobs`
- ระบุหน่วยของ `area_m2` และ `cleaning_min`
- ใช้ `jobs.shape` ตรวจจำนวนแถวและคอลัมน์
- ใช้ `jobs["room_type"].value_counts()` นับงานแยกตามประเภทห้อง

ผลที่ต้องส่ง: ขนาดตารางและจำนวนรายการของแต่ละประเภทห้อง

## 2. เปลี่ยนตัวแปรที่ใช้แบ่งสี

- สร้าง Scatter โดยใช้พื้นที่ห้องเป็น X และเวลาทำความสะอาดเป็น Y
- เปลี่ยนจาก `hue="room_type"` เป็น `hue="period"`
- ใช้ `palette={"Morning": "tab:blue", "Afternoon": "tab:orange"}`
- เปลี่ยน `hue_order` ให้ตรงกับชื่อช่วงเวลา หรือไม่ระบุเพื่อใช้ลำดับที่ Seaborn เลือก

ผลที่ต้องส่ง: กราฟพร้อม Legend และคำอธิบายว่าสีหมายถึงอะไร

คำถาม: ตำแหน่งและจำนวนจุดเปลี่ยนด้วยหรือไม่?

## 3. เปลี่ยนช่วง Histogram

เปรียบเทียบขอบช่วงสองชุด:

- `[20, 25, 30, 35, 40, 45, 50, 55]`
- `[20, 30, 40, 50, 60]`

ใช้ข้อมูลและช่วงแกน X เหมือนกันทั้งสองกราฟ เช่น 20–60 นาที

ผลที่ต้องส่ง: Histogram สองใบ และจำนวนรายการรวมในแต่ละภาพ

คำถาม: ทำไมความสูงและจำนวนแท่งเปลี่ยน ทั้งที่ไม่มีการเพิ่มหรือลบข้อมูล?

## 4. แยกค่าเฉลี่ยกับจำนวนรายการ

- สร้าง `barplot()` ของ `cleaning_min` แยกตาม `room_type` โดยใช้ `errorbar=None`
- สร้าง `countplot()` แยกตาม `room_type`
- กำหนดชื่อแกน Y ให้ตรงกับความหมายของแต่ละกราฟ

ผลที่ต้องส่ง: กราฟสองใบและคำอธิบายว่าแต่ละแท่งนับหรือคำนวณอะไร

คำถาม: ทำไม Count Plot มีแท่งสูงเท่ากัน แต่ Bar Plot มีแท่งสูงต่างกัน?

## 5. แบ่งช่องตามประเภทห้อง

- ใช้ `relplot()` เปรียบเทียบพื้นที่ห้องกับเวลาทำความสะอาด
- เปลี่ยนเป็น `col="room_type"` และ `col_order=room_order`
- ใช้ `hue="period"` พร้อม Palette ของช่วงเวลาจากข้อ 2
- ใช้ช่วงแกนเดียวกันทั้งสามช่อง

ผลที่ต้องส่ง: กราฟสามช่อง และจำนวนจุดในแต่ละช่อง

คำถาม: ทำไมตัวอย่างนี้ไม่ต้องสร้าง `plt.subplots()` ก่อน?

## 6. เปลี่ยนค่าสรุปใน Heatmap

- สร้างตารางด้วย `pivot_table()` เหมือนหัวข้อ 8
- เปลี่ยน `aggfunc="mean"` เป็น `aggfunc="median"`
- ใช้ลำดับแถวและคอลัมน์เดิม
- ใช้ช่วงสี 20–55 เหมือนกันทั้งภาพค่าเฉลี่ยและภาพมัธยฐาน
- เปลี่ยนชื่อกราฟและ Colorbar ให้ระบุ Median

ผลที่ต้องส่ง: ตารางและ Heatmap สองแบบ

คำถาม: Standard ช่วง Afternoon มีค่ามัธยฐานเท่าไร และต่างจากค่าเฉลี่ยอย่างไร?

<details>
<summary>โจทย์เสริม: กลุ่มที่ไม่มีข้อมูล</summary>

สร้างสำเนาชุดข้อมูลที่ไม่มีงาน Suite ช่วง Afternoon:

~~~python
keep = ~(
    (jobs["room_type"] == "Suite")
    & (jobs["period"] == "Afternoon")
)
jobs_missing = jobs.loc[keep].copy()
~~~

สร้างตารางสรุปใหม่ แล้วใช้ `reindex()` ให้มีแถวและคอลัมน์ครบตามเดิม

ตรวจค่าของช่อง Suite–Afternoon ก่อนนำไปวาด Heatmap

ไม่เติมศูนย์แทนช่องที่ไม่มีข้อมูล

ผลที่ต้องส่ง: ภาพและคำอธิบายว่าค่าว่างต่างจากศูนย์นาทีอย่างไร
