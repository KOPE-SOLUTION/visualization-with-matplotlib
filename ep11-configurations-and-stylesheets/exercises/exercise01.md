# แบบฝึกหัด EP11 — รูปแบบรายงานโรงผลิตและจ่ายน้ำประปา

ใช้ข้อมูล `days`, `produced` และ `distributed` จากบทเรียน โดยเก็บค่าข้อมูลเดิมไว้ตลอดการทดลอง

## 1. ปรับกราฟเฉพาะใบ

สร้างรายงานด้วย `make_report()` แล้วเปลี่ยนพื้นหลัง Axes เป็น `whitesmoke` และเพิ่มความหนาของเส้นทั้งสองเป็น 3 points ผ่าน Object ของเส้น

ผลลัพธ์ที่ตรวจสอบ: กราฟที่สร้างใหม่อีกใบโดยไม่ปรับ Object ต้องยังใช้ค่าเริ่มต้นเดิม

## 2. เปรียบเทียบขอบเขตการตั้งค่า

พิมพ์ค่า `mpl.rcParams["lines.linewidth"]` ก่อน ภายใน และหลัง `mpl.rc_context()` โดยตั้งความหนาชั่วคราวเป็น 5 points สร้างกราฟภายใน Context หนึ่งใบและหลัง Context อีกหนึ่งใบ

ผลลัพธ์ที่ตรวจสอบ: ค่าเริ่มต้นหลังออกจาก Context เท่ากับค่าก่อนเข้า ส่วนเส้นที่สร้างภายในยังหนา 5 points

## 3. ใช้สไตล์กับข้อมูลเดิม

สร้างรายงานด้วย `ggplot` และ `grayscale` อย่างละใบ โดยใช้ `plt.style.context(["default", style_name])` และคงช่วงแกนเท่าเดิม

ผลลัพธ์ที่ตรวจสอบ: ค่าของจุดข้อมูลตรงกันทั้งสองกราฟ และยังแยก Produced กับ Distributed ได้จาก Marker และเส้นประในกราฟสีเทา

## 4. สร้างไฟล์สไตล์ของตนเอง

ทำสำเนา `styles/water-report.mplstyle` เป็น `styles/water-report-large.mplstyle` แล้วเปลี่ยน:

- `font.size` เป็น 13
- `axes.titlesize` เป็น 17
- `axes.labelsize` เป็น 13
- `xtick.labelsize` และ `ytick.labelsize` เป็น 12
- `legend.fontsize` เป็น 12
- `lines.linewidth` เป็น 3

โหลดไฟล์ใหม่และสร้างรายงาน โดยไม่แก้คำสั่ง `plot()` ใน `make_report()`

ผลลัพธ์ที่ตรวจสอบ: ตัวอักษรและเส้นใหญ่ขึ้นตามค่าที่ระบุ ไม่มีข้อความทับกัน และไฟล์สไตล์ต้นฉบับยังอยู่เหมือนเดิม การปรับ `font.size` เพียงตัวเดียวไม่ทับขนาดที่กำหนดเป็นตัวเลขแยกไว้ใน Parameter อื่น

## 5. ระบุค่าให้เส้นใดเส้นหนึ่ง

ภายใน Context ที่ตั้ง `lines.linewidth` เป็น 5 ให้สร้างสองเส้น โดยเส้นหนึ่งไม่ระบุ `linewidth` และอีกเส้นระบุ `linewidth=1.5`

ผลลัพธ์ที่ตรวจสอบ: เส้นทั้งสองมีความหนาไม่เท่ากัน อธิบายได้ว่าค่าเริ่มต้นกับค่าที่ส่งให้ `plot()` ต่างกันอย่างไร

## 6. บันทึกภาพด้วยไฟล์สไตล์

ใช้สไตล์ที่สร้างในข้อ 4 แล้วบันทึกรายงานเป็น `water-week-report.png` ด้วยความละเอียด 160 dpi ภายใน Style Context และก่อน `plt.show()`

ผลลัพธ์ที่ตรวจสอบ: ไฟล์เปิดได้ มีชื่อกราฟ ชื่อแกน และ Legend ครบ และค่าข้อมูลยังตรงกับตัวอย่างเดิม
